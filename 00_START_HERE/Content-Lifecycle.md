# Content Lifecycle

```text
IDEA → DRAFT → REVIEW → ACTIVE → DEPRECATED → ARCHIVE
```

## Draft
Content exists but is not treated as authoritative operational guidance.

## Review
Check technical correctness, commands, assumptions, links, metadata, and safety.

## Active
Approved for normal reuse.

## Deprecated
A newer replacement exists; link to it.

## Archive
Move obsolete content to `99_ARCHIVE/` when it should leave normal workflows.

## Release gate

- Clear title and purpose
- Valid metadata
- Internal links resolve
- Commands reviewed
- Destructive actions clearly marked
- Verification documented
- References added when required
