# How To Use This Vault

## Find knowledge

Start from the Knowledge Map or use Obsidian search. Follow links instead of relying only on folder navigation.

## Solve a problem

Use this sequence:

1. Identify the symptom.
2. Search [[../16_TROUBLESHOOTING/]].
3. Collect the evidence requested by the troubleshooting note.
4. Open the linked [[../17_RUNBOOKS/]] only when the procedure matches the situation.
5. Use the related AI prompt to analyze evidence.
6. Validate the proposed next action.
7. Record the outcome.

## Create new knowledge

When you discover something reusable, create a small note using one of the master templates in [[../19_TEMPLATES/]].

## Link aggressively, but accurately

A link should represent a real relationship. Avoid adding links merely to increase graph density.

## Keep notes maintainable

Prefer one concept or one procedure per note. Split large notes when they start serving several unrelated purposes.
