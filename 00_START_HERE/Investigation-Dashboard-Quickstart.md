# Investigation Dashboard Quickstart

## Start

```bash
cd 35_RUNTIME
python3 product_server.py --vault .. --host 127.0.0.1 --port 8080
```

Open:

`http://127.0.0.1:8080/`

## Demo

1. **Create demo incident**
2. **Send demo telemetry**
3. Select the incident and choose **Investigate**.
4. Inspect the generated investigation.
5. Review evidence, hypotheses, unknowns and plan.

The dashboard does not expose production remediation controls.
