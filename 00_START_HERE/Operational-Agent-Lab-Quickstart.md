# Operational Agent Lab — Quickstart

The Lab is the controlled environment for validating the AI DevOps agent before connecting it to real tools.

## Start

1. Read [[../26_OPERATIONAL_AGENT_LAB/README]].
2. Read [[../26_OPERATIONAL_AGENT_LAB/scenarios/Kubernetes-NodeNotReady-Scenario]].
3. Review the fixture files.
4. Run the local simulator if desired.
5. Use [[../26_OPERATIONAL_AGENT_LAB/workflows/Operational-Agent-Evaluation-Workflow]].

## Rule

The Lab is simulation-only. Never point these workflows at production credentials or endpoints.
