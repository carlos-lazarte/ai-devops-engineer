# DevOps Principles

## Core ideas

- Automation where it reduces repeatable toil.
- Fast feedback from code to production.
- Infrastructure treated as code where appropriate.
- Observable systems with actionable signals.
- Reproducibility and version control.
- Shared responsibility for reliability.
