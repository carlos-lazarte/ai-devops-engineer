# Troubleshooting-CICD-Pipeline-Failure

Localize pipeline failures by stage, dependency, runner, environment, and reproducibility.

## First checks
Identify the first failing stage and first meaningful error, not only the final status.

## Evidence
Capture commit, runner, environment, dependency versions, command, exit code, and relevant logs.

## Branches
- Build/source failure
- Dependency/artifact failure
- Runner failure
- Test failure
- Deployment/credential failure
