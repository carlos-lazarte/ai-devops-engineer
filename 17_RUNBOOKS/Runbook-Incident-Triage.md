# Runbook-Incident-Triage

## Purpose
Establish facts, impact, and the first safe mitigation path.

## Procedure
1. Define impact and start time.
2. Identify recent changes.
3. Capture representative evidence.
4. Separate facts from hypotheses.
5. Assign owners and keep a timestamped timeline.
6. Apply changes with explicit expected effect and rollback.
7. Verify impact reduction.
