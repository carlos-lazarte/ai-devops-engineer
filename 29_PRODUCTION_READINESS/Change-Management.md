# Change Management

## Change classes

- Knowledge-only change.
- Prompt/schema change.
- Retrieval change.
- Agent-policy change.
- Tooling change.
- External-provider change.

## Required process

```text
Change proposal
   -> Review
   -> Automated validation
   -> Scenario evaluation
   -> Approval
   -> Release
   -> Post-release verification
```

Agent policy, tool permissions, and security controls should receive stricter review than ordinary documentation edits.
