# Installation Guide

## Requirements

- Obsidian Desktop
- A local copy of this Vault
- Git is recommended for version control
- Claude access is optional; the Vault remains useful without it

## Install

1. Extract the release archive.
2. Open Obsidian.
3. Select **Open folder as vault**.
4. Choose the extracted `Vault` directory.
5. Open `00_START_HERE/Welcome.md`.
6. Run through `Product-First-10-Minutes.md`.

## Optional Git setup

```bash
git init
git add .
git commit -m "Initialize AI DevOps Engineer Vault"
```

Do not commit API keys, credentials, production logs, or sensitive incident data.
