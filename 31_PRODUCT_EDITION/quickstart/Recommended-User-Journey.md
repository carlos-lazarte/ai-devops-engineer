# Recommended User Journey

### Day 1

Learn the navigation, metadata model, and troubleshooting workflow.

### Week 1

Use the runbooks and checklists on simulated or non-production cases.

### Week 2

Connect your own sanitized documentation and test retrieval.

### Week 3

Integrate Claude for analysis and structured drafts.

### Week 4

Evaluate retrieval quality and agent behavior before considering operational tool execution.

## Principle

Move from **read → explain → draft → approve → execute**. Never skip directly from an LLM answer to production change execution.
