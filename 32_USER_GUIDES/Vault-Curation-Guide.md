# Vault Curation Guide

The quality of the system depends on curation, not volume.

## Add a note

1. Select the correct note type.
2. Fill metadata consistently.
3. Separate facts from interpretation.
4. Add links to existing concepts.
5. Add references when external authority matters.
6. Validate commands before labeling a procedure as operational.

## Retire a note

Use `status: deprecated` before archiving it. Explain the replacement note when one exists.

## AI-generated content

Treat generated material as a draft until reviewed. Do not promote generated procedures to production runbooks without technical validation.
