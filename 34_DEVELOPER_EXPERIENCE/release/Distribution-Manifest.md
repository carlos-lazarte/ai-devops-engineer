# Distribution Manifest

## Required files

- `README.md`
- `CHANGELOG.md`
- `LICENSE.md`
- `VERSION`
- `00_START_HERE/`

## Optional development-only files

- `.github/`
- `34_DEVELOPER_EXPERIENCE/`
- test suites and automation

A consumer-facing distribution may omit development-only files after the release process has validated the same source tree.
