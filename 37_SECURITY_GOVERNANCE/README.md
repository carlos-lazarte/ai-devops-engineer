# 37_SECURITY_GOVERNANCE

Security, governance and policy enforcement for the AI DevOps Engineer Vault runtime.

## Scope

- identity and request context
- authorization by tool and operation
- risk classification
- approval requirements
- deny-by-default policies
- audit event requirements
- data handling and secret redaction guidance
- policy test fixtures

This layer is a control-plane baseline. It does not replace enterprise IAM, network controls, secrets management, or organizational approval processes.
