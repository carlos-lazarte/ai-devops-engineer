# Promotion to Semantic Knowledge

Historical memory is not automatically promoted into canonical knowledge.

```text
Incident / Episode
       ↓
Candidate Insight
       ↓
Duplicate / conflict check
       ↓
Human review
       ↓
Vault draft
       ↓
Technical validation
       ↓
Git review
       ↓
Canonical knowledge
```

Every promotion should retain:

- source incident IDs
- source evidence references
- reviewer
- review timestamp
- change rationale
- supersession links when applicable
