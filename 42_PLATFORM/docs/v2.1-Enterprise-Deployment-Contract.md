# v2.1 Enterprise Deployment Contract

The deployment layer promises:

1. A versioned runtime image reference.
2. Health/readiness endpoints compatible with Platform API v1.
3. Non-root, least-privilege workload baseline.
4. Externalized secret references.
5. Rollout verification and rollback guidance.
6. No production execution enabled by default.

A deployment is conformant only after environment-specific identity, network, secret, TLS, image provenance, storage and observability checks pass.
