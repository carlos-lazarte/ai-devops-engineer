# Intelligent Skill Selection Workflow

```text
User Task
  ↓
Normalize request
  ↓
Discover candidates
  ↓
Explain ranking
  ↓
Resolve dependencies
  ↓
Check platform/environment compatibility
  ↓
Apply policy
  ↓
Select admissible candidates
  ↓
Build plan
  ↓
Human / Agent review
```

The output is a plan, not an execution command.
