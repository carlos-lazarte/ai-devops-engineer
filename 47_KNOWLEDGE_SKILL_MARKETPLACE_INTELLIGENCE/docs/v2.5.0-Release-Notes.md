# v2.5.0 Release Notes

## Scope

v2.5.0 adds an intelligence layer for discovering and selecting Skills. It does not expand production execution privileges.

## Included

- deterministic task-to-Skill discovery
- explainable ranking signals
- dependency resolution
- compatibility resolution
- policy-aware selection
- plan-only orchestration
- golden evaluation dataset

## Not included

- automatic production execution
- privilege escalation
- secret retrieval
- automatic skill publication

## Validation

Run:

```bash
make marketplace-intelligence-check
```
