# Example — Kubernetes NodeNotReady

## Task
Diagnose a Kubernetes NodeNotReady incident.

## Adaptive plan
1. Retrieve incident evidence.
2. Inspect node conditions.
3. Inspect kubelet-related evidence.
4. Check recent operational changes.
5. Retrieve Kubernetes troubleshooting knowledge.
6. Retrieve the applicable runbook.
7. Discover Kubernetes troubleshooting Skills.
8. Identify missing evidence.
9. Build diagnostic hypotheses.
10. Produce a bounded plan.
11. Require human approval before any high-risk operational action.
12. Verify results after any approved change.

The planner does not decide that remediation should be executed.
