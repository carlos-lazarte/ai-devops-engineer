# Adaptive Planner

Reference implementation for deterministic task decomposition.

It is deliberately plan-only:
- no shell execution
- no SSH
- no cloud mutation
- no Kubernetes mutation
- no production execution
- no secret access

Run:
```bash
PYTHONPATH=49_ADAPTIVE_CONTEXT_AGENT_PLANNING python3 49_ADAPTIVE_CONTEXT_AGENT_PLANNING/planner/demo.py
```
