# Digital Twin Runbook

## Start

Load a scenario into the simulator.

## Inject

Apply the declared synthetic fault.

## Exercise

Run the agent only through registered simulation tools.

## Observe

Collect synthetic metrics and logs.

## Verify

Check the predeclared verification condition.

## Reset

Restore the scenario to its baseline state.

## Evidence

Persist scenario ID, correlation ID, fault ID, action IDs, and verification result.
