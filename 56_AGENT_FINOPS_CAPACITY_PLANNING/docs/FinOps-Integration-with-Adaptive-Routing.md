# FinOps Integration with Adaptive Routing

The relationship is:

```text
Usage History
   ↓
FinOps / Capacity Analytics
   ↓
Budgets
   ↓
Routing Constraints
   ↓
Adaptive Model Router
```

FinOps may provide an updated cost/latency budget only through an approved policy or configuration workflow.

A forecast must never silently become a new hard budget.
