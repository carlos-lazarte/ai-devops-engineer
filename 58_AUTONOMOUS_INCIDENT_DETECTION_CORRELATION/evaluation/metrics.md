# v3.6 Evaluation Metrics

## Detection rate
`detected relevant scenarios / total relevant scenarios`

## Correlation precision
`correctly grouped related events / all grouped events`

## False merge rate
`events incorrectly merged across unrelated groups / grouped events`

## Duplicate suppression rate
`duplicates suppressed / total duplicates`

## Time-to-candidate
Elapsed time between first qualifying event and candidate creation.

## Isolation
No cross-tenant or cross-environment correlation.

## Provenance
Every candidate must reference the signal IDs that produced it.
