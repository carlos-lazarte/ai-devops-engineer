# Safety Boundaries

v3.7 preserves the platform separation:

- **Identity** answers who is acting.
- **Policy** answers what is allowed.
- **Budget** answers whether resource consumption is allowed.
- **Approval** authorizes scoped gated actions.
- **Agent** reasons and proposes.
- **Planner** structures work.
- **Verification** determines whether the observed result supports the intended outcome.

Anomaly, correlation, prediction, incident severity, memory and model confidence are not authorization mechanisms.
