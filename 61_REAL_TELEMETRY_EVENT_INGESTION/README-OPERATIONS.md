# Operations Quickstart

1. Start the v3.8 runtime.
2. Configure `PROMETHEUS_URL` when Prometheus is reachable.
3. Send a generic normalized event or bounded OTLP metrics payload.
4. Verify telemetry persistence with `/api/v1/telemetry/events`.
5. Verify candidate creation with `/api/v1/incidents`.
6. Continue into v3.7 Incident Commander only after policy/human review.
