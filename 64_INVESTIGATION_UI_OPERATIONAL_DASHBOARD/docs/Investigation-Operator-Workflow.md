# Investigation Operator Workflow

1. Observe the incident queue.
2. Open an incident and inspect severity/confidence/provenance.
3. Start an evidence-first investigation.
4. Review facts versus hypotheses and unknowns.
5. Inspect requested diagnostics and proposed plan.
6. Use the result as an advisory investigation artifact.
7. Keep authorization and any production mutation in a separate human-controlled gate.

The dashboard deliberately avoids a one-click production remediation control.
