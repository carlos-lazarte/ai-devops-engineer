# Community Edition vs. Enterprise Direction

| Area | Community Edition | Future Enterprise Direction |
|---|---|---|
| Runtime | Local-first | Managed/on-prem enterprise profiles |
| Knowledge | Public vault and runbooks | Private organizational knowledge |
| Telemetry | Read-only connectors | Broader integrations and fleet management |
| Identity | Local reference model | SSO/OIDC/RBAC |
| Incident workflow | Dashboard + human gate | ITSM/change integrations |
| Execution | Disabled in reference runtime | Separately controlled, policy-scoped execution |
| Support | Community | Commercial support/SLA |

This table describes product direction, not a guarantee of future availability.
