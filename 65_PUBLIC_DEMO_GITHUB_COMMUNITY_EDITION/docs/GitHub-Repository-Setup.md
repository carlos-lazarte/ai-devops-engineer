# GitHub Repository Setup

Recommended public repository settings:

- Default branch protected by required CI.
- Pull requests required for changes to the default branch.
- Secret scanning and dependency alerts enabled where available.
- Issues enabled for public bug reports and feature requests.
- Discussions may be enabled later for broader architecture conversations.
- Releases should be created from annotated version tags such as `v3.13.0`.

Initial repository description:

> Local-first AI DevOps/SRE platform for evidence-first incident investigation, observability and human-controlled operations.

Suggested topics:

`aiops`, `devops`, `sre`, `incident-response`, `observability`, `rag`, `mcp`, `kubernetes`, `prometheus`, `python`, `ai-agents`

This file is a setup guide; actually making the repository public requires an explicit repository target and permission.
