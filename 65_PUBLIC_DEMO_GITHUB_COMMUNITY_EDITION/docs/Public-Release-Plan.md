# Public Release Plan

1. Start from a clean checkout.
2. Run `./65_PUBLIC_DEMO_GITHUB_COMMUNITY_EDITION/scripts/public-check.sh`.
3. Run the full test suite.
4. Run the demo smoke test.
5. Review the release manifest.
6. Commit and tag the source in Git.
7. Create the public GitHub repository or update the existing project repository.
8. Publish the release notes and checksum.

The package is GitHub-ready but is not automatically published by this build.
