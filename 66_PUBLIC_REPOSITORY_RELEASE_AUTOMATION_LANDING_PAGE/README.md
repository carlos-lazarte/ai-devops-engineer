# v3.14.0 — Public Repository, Release Automation & Product Landing Page

This module turns the v3.13 Community Edition into a release-ready public repository blueprint. It adds:

- semantic-tag release automation with GitHub Releases
- deterministic source archive generation and SHA-256 publication
- GitHub Pages deployment for a static product landing page
- optional GitHub Container Registry publication on published releases
- public repository checklist and release runbook
- commercial boundary reference and 404 page
- landing page copy for Community / Pro / Enterprise positioning
- local validation for public-release hygiene

The automation is designed so the repository can remain public while production execution stays disabled in the Community Edition reference runtime.
