# Support

## Community support

Use GitHub Issues for reproducible defects, documentation corrections and implementation questions that can be shared publicly.

Before opening an issue, include:

- Community Edition version
- Python and Docker versions when relevant
- exact command used
- sanitized logs
- expected result
- actual result

Never include API keys, access tokens, passwords, production secrets or customer data.

## Commercial support

A future commercial edition may provide enterprise integration, deployment assistance, architectural reviews and SLA-backed support. The public Community Edition does not itself include a support SLA.
