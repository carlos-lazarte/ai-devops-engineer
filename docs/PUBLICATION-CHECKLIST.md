# Public Publication Checklist

- [ ] Set repository visibility to Public.
- [ ] Review LICENSE and dependency licenses.
- [ ] Review SECURITY.md and contact channel.
- [ ] Verify no credentials or customer data are committed.
- [ ] Configure GitHub Pages to use Actions.
- [ ] Enable Actions and package permissions required by release workflows.
- [ ] Run the local deterministic demo.
- [ ] Push a semantic version tag such as `v3.14.0` after CI is green.
- [ ] Verify the GitHub Release asset and checksum.
- [ ] Verify the Pages site.
- [ ] Verify GHCR publication if enabled.
